# Mechanical assembly

The assembly drawings are the mechanical build instructions. Keep the robot
unpowered throughout mechanical assembly.

1. Build the [base frame](../../hardware/drawings/assemblies/OBX-A001_REV.pdf).
2. Build four [wheel assemblies](../../hardware/drawings/assemblies/OBX-A005_REV.pdf).
3. Fit the [electrical mounting plate](../../hardware/drawings/assemblies/OBX-A006_REV.pdf)
   and complete the [mobile base](../../hardware/drawings/assemblies/OBX-A012_REV.pdf).
4. Build the [cable carrier](../../hardware/drawings/assemblies/OBX-A011_REV.pdf)
   and [lifting module](../../hardware/drawings/assemblies/OBX-A009_REV.pdf).
5. Build the [fixed node](../../hardware/drawings/assemblies/OBX-A003_REV.pdf),
   [moving node](../../hardware/drawings/assemblies/OBX-A004_REV.pdf) and
   [horizontal actuator](../../hardware/drawings/assemblies/OBX-A010_REV.pdf).
6. Build the [balancer](../../hardware/drawings/assemblies/OBX-A007_REV.pdf) and
   [pulley block](../../hardware/drawings/assemblies/OBX-A008_REV.pdf).
7. Integrate the modules in the order shown in the
   [top-level assembly](../../hardware/drawings/assemblies/OBX-A000_REV.pdf).
8. Route cables only after checking the full travel of every mechanism by hand.
9. Install the electrical equipment according to the
   [electrical diagram](../../hardware/wiring/ObotX_electrical_diagram.pdf).

Do not substitute fastener lengths, shoulder bolts, locking nuts, bearing
bushings or cable-carrier attachment points without checking the complete
assembly model.
