# ObotX electrical diagram

The [complete electrical diagram](ObotX_electrical_diagram.pdf) is divided into
seven pages:

1. power supply, batteries, protection and distribution,
2. ARM controller,
3. Z axes,
4. X axis,
5. gripper,
6. BASE controller,
7. BASE motors and motor controllers.

Disconnect the charger and both batteries before changing any wiring. Work
through one page at a time and label both ends of each cable. Check polarity,
continuity, protective-earth connections and fuse ratings before applying
power.

After completing the wiring, follow the
[battery commissioning instructions](../../docs/power/victron-battery-commissioning.md),
[stepper-driver configuration](../../software/stm32_arm/docs/zdm-2ha865-parameters.md)
and [commissioning checklist](../../docs/testing/commissioning-checklist.md).
