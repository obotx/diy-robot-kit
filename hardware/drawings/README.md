# Mechanical drawings

Assembly drawings in [`assemblies/`](assemblies/) contain bills of materials,
exploded views and mounting instructions. Part drawings in [`parts/`](parts/)
define manufacturing dimensions, material, thickness and bending data.

Read every sheet of a drawing before assembly. The item numbers in an exploded
view refer to the bill of materials on the first sheet of that drawing.

Use the part PDFs when ordering laser-cut, bent or machined parts. Send the
matching STEP file together with the PDF, but treat the PDF dimensions,
material and tolerances as authoritative.
